E-Commerce Sales Analysis Dashboard (Power BI)
•	Problem Statement
E-commerce stakeholders need a clear, interactive view of sales performance across regions, categories, and time to optimize pricing, inventory, and promotional strategies. This dashboard transforms transactional data into actionable insights for data-driven decision-making.

•	Objectives
1.	Visualize revenue by region, product category, and order date
2.	Identify top-performing and underperforming products
3.	Track return rates and their impact on inventory
4.	Highlight seasonal and festival period sales trends
5.	Enable dynamic filtering and drill-down analysis

•	Key Insights
1.	Top 3 product categories generated 65% of total revenue
2.	Western region exhibited consistent month-over-month growth
3.	Furniture category showed a high return rate, prompting restocking adjustments
4.	Sales peaked during festival periods (October–December)

•	Tools & Technologies
1.	Power BI Desktop
2.	Microsoft Excel (sales transaction CSV)
3.	DAX for calculated columns and KPIs
4.	Slicers and drill-through filters
5.	Bar, line, and donut visuals

•	Repository Contents
1.	Ecommerce_Report.pbix – Power BI dashboard file
2.	sales_data.csv – Source transaction dataset
3.	assets/dashboard_screenshot.png – Preview image
4.	README.md – Project documentation

•	Dataset Information
1.	File: sales_data.csv
2.	Fields: OrderID, Region, Category, Subcategory, OrderDate, Sales, Quantity, Returns, Profit
3.	Prepared in Excel; cleaned and modeled in Power Query Editor

•	Target Stakeholders
1.	Sales & Marketing Managers
2.	Inventory Planners
3.	Finance Analysts
4.	Product Category Owners
5.	Executive Leadership

•	Dashboard Features & Navigation
1.	Overview: KPI cards for total sales, returns rate, and profit margin
2.	Regional Analysis: Map and bar chart showing regional sales performance
3.	Category Performance: Donut and column charts for category and subcategory revenue
4.	Trend Analysis: Line charts for monthly sales and returns over time
5.	Returns Impact: Scatter plot correlating returns with profit
6.	Interactive Filters: Date range slicer, region, and category selectors

•	Usage Instructions
1.	Open Ecommerce_Report.pbix in Power BI Desktop
2.	Ensure sales_data.csv is in the same directory
3.	Refresh the data source
4.	Use the date slicer to focus on specific periods
5.	Apply region and category filters to drill down
6.	Hover over visuals for detailed tooltips
7.	Export or share report pages as needed
